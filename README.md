# CASEME

Website tĩnh CASEME, sẵn sàng triển khai bằng GitHub Pages.

## Cấu trúc
- `index.html`: trang chính
- `images/`: hình ảnh của website
- `.nojekyll`: cho phép GitHub Pages phục vụ các file tĩnh đúng cấu trúc

## GitHub Pages
Vào **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
